INPUTS


TEXT TO TRANSLATE

"Text to translate" is the input, the text that is going to get translated multiple times.


ITERATIONS

"Iterations" is a value between 2 and 500. It represents the amount of time to translate. The last iteration will always be in the Last Language selecteded by you.


OUTPUT LANGUAGE

"Output Language" is the language Google Trash will use as the Last Iteration.

Not every language is available, obviously, but I'm trying my best to add as much languages as possible.


ADVANCED INPUTS

Advanced Inputs should ONLY be used by Advanced Users that knows what everything below does.

ALLOW ACCURACY

"Allow Accuracy" allows users to add an "Accuracy System" on the translations. Check below for more details.


MIN. ACCURACY

"Min. Accuracy", or Minimum Accuracy can only be shown if "Allow Accuracy" is enabled. The value has to be between 0 and 100, which represents the "accuracy" of the translation based on the last one.

Calculations: TRANSLATED TEXT divided by BEFORE TRANSLATION TEXT

If the accuracy is below the Minimum Accuracy, the translation is cancelled and the text is translated into another language.
